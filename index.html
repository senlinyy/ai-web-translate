AI Web Translate

Read webpages in two languages with Claude or ChatGPT.

What you need

  • macOS (Linux should work but is untested; Windows is not supported).
  • Node.js 22 or newer.
  • For Claude models: Claude Code, signed in with your Claude subscription or Anthropic Console account.
  • For ChatGPT models: a ChatGPT account (you sign in from the extension; the installer downloads its own Codex runtime).

1. Install the extension

Get it from the Chrome Web Store

2. Install the companion

The companion is a small local app that connects the extension to Claude Code or Codex on your computer.

Download companion 0.9.0
  1. Unzip the download and open Terminal in the unzipped folder.
  2. Run the installer, then the check: 
    npm run install:companion
npm run doctor
  3. For Claude models, sign in to Claude Code once (if you haven't): 
    claude auth login
    Use claude auth login --console to use Anthropic API billing instead of a subscription.
  4. Restart Chrome (or turn the extension off and on in chrome://extensions).

Keep the unzipped folder only until the installer finishes; the companion is copied to ~/Library/Application Support/AI Web Translate.

3. Translate

  1. Open a webpage and click the AI Web Translate icon.
  2. Choose a model (Claude Haiku 5.5 is fastest), then Translate page. Press Option+Shift+T to toggle without the popup.
  3. For ChatGPT models, click Sign in with ChatGPT first.
  4. To translate selected text in a floating card on any site, open the extension's settings and turn on Selection translation.

What is sent where

Nothing is sent until you start a translation. The text you translate goes from the extension to the companion on your computer, then to Anthropic (Claude) or OpenAI (ChatGPT) under your own account. The developer receives nothing. Settings and cached translations stay in your browser.

Uninstall

Remove the extension in Chrome, then delete ~/Library/Application Support/AI Web Translate and ~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.ai_web_translate.host.json.
